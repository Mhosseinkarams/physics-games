# Physics Games

A collection of 2D games built with Python and Pygame, focusing on manual physics implementation and educational gameplay.

## Games

### 1. [Ballistic Range](./ballistic_range/)
A physics prediction game where you must calculate the trajectory of a projectile to hit various targets.
- **Key Features:** Manual kinematics implementation, live math displays, progressive difficulty.
- **Physics Concepts:** Projectile motion, quadratic formula, Euler integration, wind effects.

## How to Run

Each game is located in its own directory. To run a specific game, navigate to the root directory and use the following command structure:

```bash
python -m <game_directory_name>
```

For example, to run Ballistic Range:
```bash
python -m ballistic_range
```

See the individual game directories for more detailed instructions and physics explanations.
